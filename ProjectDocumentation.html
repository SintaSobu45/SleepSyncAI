01Project Overview

SleepSync AI is an educational wellness web application that helps users understand their self-reported sleep and daily energy patterns. Users fill out a 6-field sleep questionnaire, and the app generates personalized informational reports with practical sleep-routine suggestions. Users can also download their analysis as a professionally formatted PDF report.

⚠️ Important Disclaimer This is an informational wellness tool, NOT a medical diagnostic application. It does not diagnose sleep disorders, determine biological chronotypes, or provide medical advice.

Project Objectives

  • Provide a user-friendly interface for entering sleep pattern data
  • Analyze sleep data using AI (Google Gemini) or rule-based algorithms
  • Generate personalized, actionable sleep suggestions
  • Create downloadable professional PDF reports
  • Work fully offline without requiring an AI API key
  • Maintain user privacy — no data is stored or persisted

02Features & Functions

Core Features

🛏️ Sleep Questionnaire

6-field interactive form with bedtime, wake-up time, energy peak, preferred schedule, sleep duration slider, and optional notes. Client-side validation with clear error messages.

🤖 AI-Powered Analysis

Uses Google Gemini API (gemini-2.0-flash model) for natural language sleep pattern analysis with personalized, conversational insights.

📊 Rule-Based Fallback

Deterministic scoring algorithm (0–9 scale) that works without any API key or internet connection. Automatically activates when AI is unavailable.

📄 PDF Report Generator

Server-side PDF generation using QuestPDF. Creates branded A4 reports with all analysis sections, page numbering, and professional layout.

🌙 Dark Mode UI

Premium dark theme with glassmorphism effects, gradient accents, Inter typography, and smooth micro-animations for a modern look.

🔒 Privacy First

No data persistence, no user accounts, no cookies. Stateless architecture ensures all data is processed in-memory and never stored.

Request Flow

  1. User fills form → Client-side validation runs → Data sent via Axios POST
  2. Backend validates → Regex time format check → HTML sanitization on notes
  3. Analysis runs → Gemini AI (if key configured) or Rule-Based fallback
  4. Response returned → JSON with summary, preference, suggestions, recommendations, disclaimer
  5. Results displayed → Fade-in animation, smooth scroll to results section
  6. PDF download → Same data re-analyzed server-side → QuestPDF generates A4 → Blob download

09How the Analysis Engine Works

Dual-Engine Architecture

The application uses a strategy pattern with two interchangeable implementations:

EngineActivation ConditionInternet RequiredResponse Style
GeminiAnalyzerService Gemini API key is configured ✅ Yes Natural language, conversational, AI-generated
RuleBasedAnalyzerService No API key OR Gemini fails ❌ No — fully offline Template-based, deterministic, consistent

Rule-Based Scoring Algorithm

The fallback engine uses a 3-factor scoring system to estimate schedule preference:

FactorScore 0Score 1Score 2Score 3Score 4
Bedtime 8–10 PM 10–11:30 PM 11:30 PM–1 AM 1–4 AM —
Energy Peak Early Morning Late Morning Afternoon Evening Night
Preferred Schedule Early Flexible Late — —

Total score range: 0–9

  • 0–2: Early-oriented
  • 3–5: Intermediate
  • 6–9: Late-oriented

Overnight Sleep Duration Calculation

The engine correctly handles midnight crossover:

  • Same-day: 01:00 → 09:00 = 8 hours (wakeUp – bedtime)
  • Overnight: 23:00 → 07:00 = 8 hours (24 – bedtime + wakeUp)

Personalized Suggestions Logic

Three contextual suggestions are generated based on:

  1. Sleep duration: Under 6h (increase), over 9h (consult doctor), 6–9h (maintain)
  2. Energy alignment: Morning peak + late schedule (misaligned), evening peak + early schedule (misaligned), else (well-aligned)
  3. Bedtime habits: After midnight (darkness/quiet advice), before 10 PM (protect schedule), else (reduce screen time)

12Security Measures

MeasureImplementation
API Key Protection Gemini API key is read server-side only from User Secrets, appsettings, or environment variable. Never sent to frontend.
Input Validation Data annotations + regex validation on all required fields. Additional TimeSpan.TryParse check on time fields.
HTML Sanitization Notes field is stripped of all HTML tags using Regex.Replace(notes, "<[^>]*>", "") before processing.
Error Handling Global exception handler returns generic error message. Stack traces are never exposed to clients.
CORS Policy Restricted to specific frontend origins (localhost:5173 and :3000). Not open to all origins.
Server-Side Report PDF report re-runs analysis on the server. Client cannot inject fabricated analysis data into the report.
No Data Persistence No database, no cookies, no sessions. All data is processed in-memory and discarded after the response.
AI Safety Prompt Gemini prompt includes strict rules: no medical diagnosis, no chronotype claims, cautious language only.
